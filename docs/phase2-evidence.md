## Trust boundary — verified from outside

`GET /env-proof` on the live sandbox:

```json
{"service":"aion-sandbox","credentials_found":0,
 "credential_variable_names":[],"verdict":"ZERO_CREDENTIALS",
 "ignored_public_variables":["GPG_KEY"],
 "service_account_roles":"none granted"}
```

The sandbox runs under a service account with **zero IAM roles**. Using the
default compute account would have handed it real project permissions via
the metadata server — the "no credentials" claim would have been true of
environment variables and false of identity.

`GPG_KEY` is the `python:3.11-slim` base image's public Python signing key
id. It is disclosed in the response rather than filtered silently, because
an allowlist a reader cannot see is not a proof.

**This was caught by curling the live service. The local test passed.**
